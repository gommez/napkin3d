# Roadmap

## Now: first usable MVP

Local project/folder/part hierarchy; camera/gallery; manual line/rectangle/circle tracing; selection, handles and mm editing; undo/redo; grid/feature snapping; photo calibration; extrusion; 3D orbit and orientation; SVG/STL; Pages and home-screen manifest.

## Next: validate on real phones

- Test Safari/iPhone and Chrome/Android camera, downloads, installation, storage persistence and touch gestures.
- Add project backup/import, granular persistence and cross-session history if useful.
- Add two-finger 2D navigation, better calibration markers and folder organization tools.
- Improve offline update handling and storage quota management.

## Later, only after validation

Robust boolean operations/holes, arbitrary closed profiles, constrained dimensions, additional primitives and export adapters (3MF, DXF, STEP, OBJ, PDF). Automatic CV/OCR/AI interpretation and cloud services are outside this MVP.
